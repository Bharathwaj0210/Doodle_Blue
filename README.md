# Doodle Blue Training

This repository contains the Doodle Blue web development training exercises. It includes introductory HTML and CSS pages, JavaScript practice, and a multi-page student campus website.


## Contents

### Day 1: HTML and CSS

The `Day-1 (HTML,CSS)` folder contains introductory pages demonstrating:

- Basic HTML page structure
- Navigation between pages
- Forms and input controls
- Styling with an external CSS file

### JavaScript

The `JS` folder contains JavaScript learning material and examples covering core concepts and browser interactions.

### Student Campus Website

The `task` folder contains a multi-page student campus website with pages for:

- Home
- About
- Events
- Event details
- Schedule
- Registration

## How to Run

No build tools or dependencies are required. To view a page:

1. Clone or download this repository.
2. Open any `.html` file in a web browser.
3. Use the links within each page to navigate through the related exercises.

For the best experience, open the project folder in Visual Studio Code and use a local web server extension such as **Live Server**.
